# 🎯 나만의 과학 및 생활 상식 퀴즈 게임

## 1. 프로젝트 개요

Python을 활용하여 제작한 콘솔 기반 퀴즈 게임입니다.

과학과 생활 속의 재미있는 상식을 퀴즈로 풀어보며,
Python의 기초 문법과 객체 지향 프로그래밍을 학습하기 위해 제작했습니다.

## 2. 퀴즈 주제 선정 이유

평소 일상생활 속에서 접하는 과학 지식과 자연현상에 관심이 있어
누구나 재미있게 풀 수 있는 과학 및 생활 상식이라는 주제를 선정했습니다.

## 3. 실행 방법

Python 3.10 이상이 필요합니다.

터미널에서 프로젝트 폴더로 이동한 후 다음 명령어를 실행합니다.

```bash
python main.py
```

## 4. 주요 기능

- 퀴즈 풀기
- 퀴즈 추가
- 퀴즈 목록 확인
- 최고 점수 확인
- 퀴즈 랜덤 출제
- JSON 파일 데이터 저장 및 불러오기
- 잘못된 입력 및 오류 처리

## 5. 파일 구조

```text
MY_QUIZ_GAME/
│
├── main.py
├── quiz.py
├── quiz_game.py
├── state.json
├── README.md
├── .gitignore
└── LICENSE
```

## 6. 데이터 파일 설명

### state.json

프로젝트 루트에 위치하며 퀴즈 데이터와 최고 점수를 저장합니다.

- quizzes: 등록된 퀴즈 목록
- best_score: 최고 정답 개수

UTF-8 인코딩과 JSON 형식을 사용합니다.

프로그램을 다시 실행해도 저장된 데이터가 유지됩니다.

## 7. 개발 환경

- 운영체제: Windows
- Python: 3.12.10
- 개발 도구: Visual Studio Code
- 버전 관리: Git / GitHub
